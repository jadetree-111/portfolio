## 使用说明

- 可直接浏览、下载本仓库中的文档、代码与设计文件；视频可进入对应文件查看或下载。
- 知速达的安装与运行方式见其项目说明。
- Daily Hub 需要 Node.js 22.13 或更高版本。在 `daily-hub` 目录执行 `npm ci`，将 `.env.example` 复制为 `.env` 并填写自己的配置，再执行 `npm start`。
- 配置示例中的密钥由使用者自行提供。本仓库不包含本机密钥、个人数据库、依赖目录或测试运行缓存。
